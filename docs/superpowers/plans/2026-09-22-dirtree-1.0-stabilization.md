# Icod.DirTree 1.0 Stabilization Implementation Plan

**Goal:** Make `dirtree` safe, predictable, testable, and release-ready for version 1.0.0.

**Architecture:** Keep the package as a single .NET tool. Route parsed options into an internal asynchronous tree renderer that owns traversal, link policy, escaping, and diagnostics. Exercise the command boundary with xUnit tests and exercise the packed executable on every supported operating system.

**Tech stack:** .NET 10, C# 13, Icod.CommandFramework, Icod.Path, xUnit, PowerShell 5.1-compatible packaging scripts.

## Tasks

1. Add an xUnit test project to the solution and write failing command-level tests for usage errors, stream injection, depth, hidden entries, files, ordering, ASCII output, escaping, cancellation, missing paths, and link traversal.
2. Replace the public iterator and custom immutable stack with an internal asynchronous renderer using `System.Collections.Generic.Stack<T>`.
3. Add conventional `-a`/`--all`, `-L`/`--follow-links`, and `--ascii` options; reject invalid depths with status 2.
4. Make links visible but non-traversed by default, resolve followed links physically with `Icod.Path`, and stop cycles deterministically.
5. Route all output through `CommandContext`, propagate cancellation from `Program`, escape control characters, report traversal failures, and define statuses 0, 1, 2, and 130.
6. Set all version surfaces to 1.0.0 and derive `--version` from assembly metadata.
7. Update the man-page README, add a changelog, complete package metadata, and strengthen packed-tool smoke validation.
8. Verify build, tests, package contents, packed installation, and cross-platform GitHub Actions before requesting review.
